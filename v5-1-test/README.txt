MoraFiq 5.1 — تحديث واجهات الاختبار فقط

1. احتفظ بالنسخة القديمة app.html وبمجلد v5-test كما هما.
2. أنشئ مجلد v5-1-test في GitHub وارفع ملفات هذه الحزمة داخله.
3. انسخ config.js من v5-test إلى v5-1-test محليًا أو عدله بنفس قيم URL والمفتاح العام. ملف config.js في الحزمة قالب بلا مفاتيح.
4. لا تنفذ schema.sql مجددًا؛ نفس مشروع Supabase التجريبي ونفس الجداول الحالية.
5. افتح v5-1-test/admin.html واختبر إسناد المستشار عبر قائمة المقاطعات.
6. افتح v5-1-test/center.html واختبر تحديث المجاميع.
7. لا تستخدم بيانات تلاميذ حقيقية أثناء الاختبار.

التغييرات: قائمة مقاطعات بدل نسخ UUID، منع التسجيل كمسؤول موقع من واجهته، تحسين التحقق من أعداد الإحصائيات والفترة، تحديث البيانات دون إعادة تحميل الصفحة، منع الضغط المكرر على عمليات حساسة.

الحدود: لم تختبر الاتصالات الحية؛ هذه النسخة لا تنقل وظائف الإصدار 4.x، ولا تتضمن SQL جديدًا. الإحصائيات تُجمع عند ثلاثة مساهمين على الأقل.
